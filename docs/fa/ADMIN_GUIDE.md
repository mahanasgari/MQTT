# راهنمای پنل مدیریت پلتفرم

پنل **مدیریت پلتفرم** برای اپراتورها — جدا از «ادمین خانه» که مشتریان برای یک household دارند.

## دسترسی

کاربر باید یکی از این شرایط را داشته باشد:

1. شماره در `PLATFORM_ADMIN_PHONES` در `.env` بک‌اند
2. یا `is_platform_admin=true` در جدول `users`

پس از ورود OTP، لینک **مدیریت** در نوار بالا ظاهر می‌شود یا مستقیم بروید به:

- فارسی: `/fa/admin`
- انگلیسی: `/en/admin`

## بخش‌ها

| صفحه | کاربرد |
|------|--------|
| نمای کلی | تعداد کاربران، خانه‌ها، دستگاه‌ها، آنلاین |
| کاربران | لیست همه کاربران |
| دستگاه‌ها | لیست همه دستگاه‌ها؛ ثبت سریال کارخانه؛ توکن جفت‌سازی |
| خانه‌ها | لیست householdها |
| رویدادها | آخرین رویدادهای پلتفرم |

## ثبت سریال کارخانه

وقتی `REQUIRE_PREREGISTERED_SERIAL=true`:

1. **مدیریت → دستگاه‌ها**
2. فرم «ثبت سریال کارخانه» — مثلاً `SN-2026-000001`
3. مشتری با توکن جفت‌سازی ثبت می‌کند

## ایجاد توکن جفت‌سازی

1. **مدیریت → دستگاه‌ها → ایجاد توکن**
2. سریال اختیاری (برای قفل توکن روی یک دستگاه)
3. توکن را به مشتری یا برچسب دستگاه بدهید
4. TTL پیش‌فرض: ۲۴ ساعت (`PAIRING_TOKEN_PROVISION_TTL_HOURS`)

## API (برای اتوماسیون)

همه با JWT کاربر ادمین:

| متد | مسیر |
|-----|------|
| GET | `/v1/admin/stats` |
| GET | `/v1/admin/users` |
| GET | `/v1/admin/devices` |
| POST | `/v1/admin/devices` |
| PATCH | `/v1/admin/devices/{id}` |
| GET | `/v1/admin/households` |
| POST | `/v1/admin/pairing-token` |
| GET | `/v1/admin/events` |

## نکات

- حذف نرم دستگاه: PATCH با `soft_delete: true`
- قطع از خانه: PATCH با `unlink: true`
- مشتریان عادی این APIها را نمی‌بینند (403)
